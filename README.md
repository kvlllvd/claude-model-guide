# Когда переключать модель

Одностраничный гайд по выбору модели и уровня усилия в Claude Code —
на примере задач проекта Knowly.

- `index.html` — весь лендинг: разметка, стили и шрифты в одном файле.
  Никакой сборки, никаких зависимостей. Открывается двойным кликом.

## Что внутри

- Четыре модели (Haiku 4.5 · Sonnet 5 · Opus 5 · Fable 5) и относительная цена
- Пять уровней усилия: `low` → `max`
- Три вопроса, по которым выбирается связка
- Таблица реальных задач Knowly с готовым ответом «модель + усилие»
- Пять правил переключения и три способа переключить

## Адаптив

Одна колонка на телефоне, три брейкпоинта. Таблица задач на экранах уже 640 px
превращается в карточки — горизонтальной прокрутки нет. Тёмная тема берётся из
системной настройки, есть стили для печати.
